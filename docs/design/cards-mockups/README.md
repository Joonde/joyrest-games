# Макеты карточного стола (покер, дурак, блэкджек)

Исходники холста «JoyRest Карты — макеты» (Claude, 10 октября 2026): экраны зала, телефоны,
пульт, 10 колод, голосование за колоду. Файлы `.dc.html` — архив дизайна, в сборку не входят.
Картинки в них ссылаются на хранилище холста (`/_blob/…`); полноразмерные оригиналы лежат
в `public/cards/art/` (список и источники — `public/cards/art/manifest.json`).
