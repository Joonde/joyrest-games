# Шаблон истории

Объём готовой истории — 10–15 страниц. История существует в двух формах:

1. **Текст для ведущего** — этот документ: атмосферный, читается вслух и пересказывается.
2. **Схема сцен** — те же сцены как данные для игры (см. `данные/story.example.json`). Её собирают в конструкторе по этому документу.

Правила:

- точки входа описываются **ролями**, а не именами богов, и у каждой есть запасной вариант для любого бога;
- в каждом диалоге минимум 3 исхода, лучше все 5 (крит. удача / хорошо / средне / плохо / крит. неудача);
- и успех, и провал ведут к интересному продолжению, ветки быстро сходятся к узловым сценам;
- суммарные награды укладываются в норму: до 15–20 очков на игрока и 1–2 артефакта на группу;
- у каждого существа указан рейтинг (F–SSS) и скрытая сила;
- в конце — крючки на другие истории.

## 7. Сцены (6–9 страниц)

Обычно 6–10 сцен. Каждая сцена оформляется так:

### Сцена N. Название

- **Где:** мир, место.
- **Кто участвует:** все / выбор кубиком («мешок судьбы») / роль.
- **Вставки по флагам Саги:** если флаг X — что меняется.

**Текст для ведущего** (читать вслух, 1–2 абзаца):

> …

**Проверка:** характеристика, сложность (0 / +10 / +20 / −10).

| Исход | Что происходит | Награда | Флаги | Следующая сцена |
| --- | --- | --- | --- | --- |
| Крит. удача (96–100) | | | | |
| Хорошо | | | | |
| Средне | | | | |
| Плохо | | | | |

**Бой (если есть):** враги, их рейтинг, цель боя (победить / сбежать / продержаться N ходов).

# Пример заполнения: «Вечная зима» (фрагмент)

## 1. Паспорт

| Поле | Значение |
| --- | --- |
| Название | Вечная зима |
| Код | ST-001 |
| Миры | Земля смертных, Царство Аида, Внеграничье |
| Уровень угрозы | 2 |
| Длительность | 90–120 минут |
| Игроки | 3–6 |
| Тон | мрачная эпика, расследование |
| Вход | `persephone_captured` — если уже стоит, история начинается сразу у Леты; `cerberus_gone` — если стоит, вход в Аид без стража |
| Выход | `persephone_saved` или `eternal_winter`; всегда `dark_mark_found` |
| Крючки | «Цербер сорвался с цепи», «Второй огонь» (метка Тёмного мира) |
| Норма наград | до 15 очков на игрока, 2 артефакта на группу |

## 2. Миф-основа

Аид похитил Персефону. Деметра в горе остановила рост всего живого. Персефона съела зёрна граната и с тех пор полгода живёт у Аида, полгода — у матери. Так появились зима и весна.

## 3. Поворот

Время возвращения прошло, но Персефоны нет ни внизу, ни наверху. Зима не кончается, королевства голодают и винят богов.

## 4. Правда для ведущего

Персефону поймали пожиратели Внеграничья: они питаются её силой весны. Их направляет демон Тёмного мира — на пожирателях его метка. Если ничего не делать, через три сцены зима становится вечной (`eternal_winter`).

## 5. Роли

| Роль | Лучше подходят | Зацепка | Запасной вариант |
| --- | --- | --- | --- |
| Союзник Деметры | Гестия, Геба, Артемида | Деметра лично просит о помощи | любой бог, чьи последователи голодают |
| Подозреваемый | Аид, Гермес | последним видел Персефону | любой бог, которого голодные королевства обвиняют |
| Знающий ночные пути | Геката, Селена, Нюкта | видит следы в темноте | любой бог с картой ночных троп |

## 7. Сцена 1. Голодный храм

- **Где:** Земля смертных, храм Деметры в королевстве людей.
- **Кто участвует:** все.
- **Вставка:** если `prometheus_free` — в храме горит чёрный огонь, сложность +10.

> Снег лежит на ступенях храма уже восьмой месяц. Внутри — толпа голодных людей и Деметра, постаревшая от горя. Она поднимает глаза на вошедших богов: «Вы пришли помочь… или вы тоже лжёте мне?»

**Проверка:** Влияние, сложность 0.

| Исход | Что происходит | Награда | Флаги | Следующая сцена |
| --- | --- | --- | --- | --- |
| Крит. удача | Деметра доверяет и отдаёт серп, который чувствует жизнь | +5 очков, артефакт «Серп Деметры» | `demeter_trust` | 2 |
| Хорошо | Деметра рассказывает о последнем видении дочери | +3 | `demeter_trust` | 2 |
| Средне | Деметра называет только место — Ахерон | +2 | — | 2 |
| Плохо | Деметра холодна; толпа ворчит | +1, отношение Деметры −10 | — | 2 |
| Крит. неудача | Толпа нападает на «лживых богов» | 0, Влияние −2 | `mob_angry` | 1Б (бой с толпой, рейтинг F) |
