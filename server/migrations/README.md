# Миграции базы

Файлы `NNNN_название.sql` (латиница, цифры, `_`) выполняются по порядку при выкладке,
каждый в своей транзакции (`server/src/migrate.ts`). Выполненные записаны в `schema_migrations`.

Миграции только добавляют: новые таблицы, колонки (с `default` или `null`), индексы.
Переименование и удаление — в два шага через две выкладки, иначе откат на прошлую версию
сломается.
