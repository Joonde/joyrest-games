# Адаптер Flic Hub для JoyRest

Официальный путь: Flic 2 или Flic Duo → Flic Hub → Flic Hub Studio → компьютер ведущего → пульт JoyRest.

## Что нужно

- Flic Hub с доступом к Flic Hub Studio.
- Одна или несколько кнопок Flic 2 / Flic Duo.
- Компьютер ведущего и Hub в одной локальной сети.
- Node.js 22 или новее на компьютере ведущего.

## Настройка

1. Запустите программу с доступом из локальной сети:

```bash
JOYREST_HARDWARE_HOST=0.0.0.0 npm start
```

2. Программа напечатает адрес и **ключ адаптера Flic Hub**. Не публикуйте ключ в репозитории или Telegram.
3. В Flic Hub Studio создайте модуль и вставьте содержимое `main.js`.
4. В начале модуля замените:
   - `COMPANION_URL` на `http://IP_КОМПЬЮТЕРА:43127`;
   - `ADAPTER_KEY` на ключ из консоли.
5. Запустите модуль и включите автоматический перезапуск после сбоя.
6. Добавьте кнопки в Flic Hub обычным способом производителя.
7. В пульте JoyRest откройте «Кнопки» и сопрягите пульт с программой по одноразовому коду.

События `buttonAdded`, `buttonConnected`, `buttonReady`, `buttonDisconnected` и `buttonDown` преобразуются в общий формат JoyRest. У каждой кнопки используется её Bluetooth-адрес как стабильный идентификатор, поэтому повторное подключение не создаёт новую привязку.

## Проверка

- Нажатие появляется в списке устройств пульта как `Flic XXXX`.
- Назначьте его команде и выполните проверку.
- В игре используется только `buttonDown`, поэтому отпускание не создаёт второй ответ.
- Последовательности событий защищены от повторной доставки одного `eventId`.

Реальное аппаратное испытание ещё не выполнено: нужен Flic Hub и кнопка. Совместимость кода подтверждается автотестами адаптера, а не присутствием устройства у разработчика.
