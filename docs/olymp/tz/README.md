# «Олимп» — пакет ТЗ

Ролевая игра про греческих богов для игровой платформы автора. Версия пакета 1.0 от 10.10.2026.

## Что внутри

| Файл | Что это |
| --- | --- |
| `TZ_Olymp.md` | Техническое задание — главный документ. Решения автора помечены [РЕШЕНО], проработанные варианты — [ПРЕДЛОЖЕНИЕ], вопросы — [ОТКРЫТО] |
| `TZ_Olymp.docx` | То же ТЗ в формате Word |
| `шаблоны/01_шаблон_истории.md` | Шаблон истории на 10–15 страниц + пример заполнения («Вечная зима») |
| `шаблоны/02_шаблон_существа.md` | Карточка любого существа: рейтинг F–SSS, скрытая сила, отношение |
| `шаблоны/03_шаблон_артефакта.md` | Артефакт со свойствами по исходу броска |
| `шаблоны/04_шаблон_бога.md` | Карточка бога + промпт для генерации портрета |
| `шаблоны/05_шаблон_мира.md` | Шаблон мира / уровня вселенной |
| `шаблоны/данные/*.json` | Примеры формата данных для сервера и конструктора: история, существо, артефакт, бог, Сага |
| `макеты/*.jpg` | Превью портретов Зевса, Аида и Афины (уменьшенные) |

## Как пользоваться в другом чате

1. Загрузите архив и попросите прочитать `README.md` и `TZ_Olymp.md`.
2. Новый контент (истории, существа, артефакты, боги, миры) делайте строго по шаблонам из папки `шаблоны/`.
3. Для разработки опирайтесь на раздел 14 ТЗ (архитектура) и на JSON-примеры: это формат данных, под который пишется сервер.
4. Перед реализацией закройте открытые вопросы из раздела 17 ТЗ.
