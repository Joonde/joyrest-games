# Шаблон артефакта

Правила:

- у персонажа 4 слота; новый артефакт берётся обязательно, заменяя один из старых;
- плохой артефакт можно положить в «сумку»: действует до конца истории, потом игрок решает, оставить ли его;
- свойства «просыпаются» по броску — один артефакт у разных игроков может оказаться разным;
- суммарный бонус всех артефактов к одной характеристике — не выше +15; итоговое значение — не выше 95.

Данные для игры: `данные/artifact.example.json`.

## Поля

| Поле | Заполнить | Подсказка |
| --- | --- | --- |
| Название | | |
| Код | | `AR-001` |
| Редкость | | обычный / редкий / эпический / легендарный |
| Чей | | общий или уникальный для бога |
| Мир происхождения | | |
| Где добывается | | история, сцена, существо |
| Лор | | 1 абзац: откуда, связь с мифом |
| Особое действие | | если есть: что делает в бою или диалоге, сколько раз |

## Свойства по исходу броска

| Исход | Плюсы | Минусы | Особое действие |
| --- | --- | --- | --- |
| Крит. удача (96–100) | все | нет | да |
| Хорошо | почти все | нет | да |
| Средне | основные | мелкий минус | нет |
| Плохо | половина | заметный минус | нет |
| Крит. неудача (1–5) | один | сильный минус или проклятие | искажённое |

## Пример: «Молния Киклопов»

| Поле | Значение |
| --- | --- |
| Редкость | легендарный |
| Чей | уникальный для Зевса; у других богов — свойства «Средне» как максимум |
| Мир | Тартар (кузня киклопов) |
| Где добывается | история «Сон царя богов», освобождение киклопов |
| Лор | Киклопы выковали Зевсу первую молнию в благодарность за освобождение из Тартара. Эта — вторая, недоделанная. |

| Исход | Свойства |
| --- | --- |
| Крит. удача | +6 Мощь, +3 Мудрость, особый удар раз в бой (урон ×2) |
| Хорошо | +5 Мощь, +2 Мудрость, особый удар раз в историю |
| Средне | +4 Мощь, −1 Мудрость |
| Плохо | +3 Мощь, −3 Мудрость |
| Крит. неудача | +3 Мощь, −4 Удача; при крит. неудаче в бою молния бьёт союзника |
