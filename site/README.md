# JoyRest — сайт «Радость без хлопот»

Структура:
- index.html — главная страница (загружать на хостинг именно под этим именем, в корне)
- css/style.css — все стили (включая тёмную тему и адаптацию под телефоны)
- js/script.js — вся логика: пикер повода, фильтры, калькулятор, формы, отправка в Telegram
- img/logo.png — логотип
- fonts/ — пусто: шрифты Cormorant Garamond и Jost подключаются с Google Fonts (ссылка в index.html)
- extras/ (перенесено в docs/site-extras/, на сайт не выкладывается) — промо-ролик (joyrest-promo.html), описание сайта, статья для Дзена, исходная сетка логотипов, описание игр

Внешние ресурсы (нужен интернет): Google Fonts, фоновое фото Unsplash (css/style.css), виджет поста Telegram.

Как выложить на Netlify: перетащить папку site (или содержимое) на https://app.netlify.com/drop — index.html должен лежать в корне.

ВАЖНО: токена Telegram-бота в коде сайта больше нет. Заявки будут уходить на сервер (POST /api/lead), а токен хранится только на сервере. Старый токен нужно перевыпустить у @BotFather (/revoke).
