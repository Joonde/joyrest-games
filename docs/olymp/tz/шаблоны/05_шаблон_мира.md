# Шаблон мира (уровня вселенной)

Подходит для любого мира: Олимп, королевство, круг Ада, Тёмный мир, Внеграничье, туманный мир.

## Поля

| Поле | Заполнить | Подсказка |
| --- | --- | --- |
| Название | | |
| Код | | `WD-01` |
| Тип | | уровень / королевство / круг Ада / туманный мир |
| Место во вселенной | | что выше, что ниже, с чем граничит |
| Кто правит | | бог, раса, демон, никто |
| Главный закон мира | | одно правило, которое здесь нельзя нарушить |
| Игровой эффект | | как закон меняет броски, бой, диалоги |
| Как попасть | | врата, условие, страж |
| Как выйти | | |
| Скрыт туманом? | | да/нет; условие открытия |
| Кто сильнее здесь | | боги и существа с бонусом |
| Кто слабее здесь | | |
| Обитатели | | список существ с рейтингом |
| Ключевые места | | 3–7 локаций для сцен |
| Стиль кубика | | цвет и материал (золото, кость, лёд…) |
| Визуал и звук | | палитра, освещение, музыка |
| Лор | | 1–3 страницы: история мира, связь с мифами, что здесь происходит сейчас |
| Крючки для историй | | 3–5 идей |

## Пример: 9-й круг Ада — Коцит

| Поле | Значение |
| --- | --- |
| Тип | круг Ада |
| Место | дно Ада, ниже 8-го круга; под ним — Тартар |
| Кто правит | Люцифер, вмёрзший в центр озера |
| Главный закон | здесь замерзает всё, что движется без цели |
| Игровой эффект | каждый ход без действия — Стойкость −3; огонь и свет ослаблены (−10 к броскам) |
| Как попасть | спуститься с 8-го круга; гиганты у входа |
| Как выйти | только вверх, через гигантов, или вниз — в Тартар |
| Сильнее здесь | ледяные демоны, Аид (+5) |
| Слабее | Гелиос, Аполлон, Прометей (−10) |
| Ключевые места | озеро Коцит, четыре зоны предателей, колодец гигантов |
| Стиль кубика | ледяной, с инеем |
| Крючки | в лёд вмёрзла душа, которую ищет кто-то из богов; во льду — молния, потерянная Зевсом |
