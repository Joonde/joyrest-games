Инструкция для владельца: всё делается с телефона (Termius и браузер).
Сервер: `217.114.13.92`, сайт: https://games.joy-rest.ru, заглушка: https://joy-rest.ru.

Команды для Termius даны готовыми блоками: скопируйте блок целиком и вставьте.

## Что хранить у себя (не на сервере)

Без этого при потере сервера восстановиться нельзя. Храните в менеджере паролей или
в защищённой заметке, не в чатах.

| Что | Откуда | Зачем |
|---|---|---|
| Ключ Termius (Keychain) | создаёте сами в Termius | вход на сервер |
| Пароль root в панели Beget | панель Beget | аварийная консоль (VNC), если вход по ключу сломался |
| Токен GitHub `read:packages` и **дата его окончания** | GitHub → Developer settings | сервер скачивает образы |
| Пароль restic и ключи Beget S3 | покажет настройка бэкапов (PR 6) один раз | без них копии в S3 не расшифровать |
| Почта и пароль admin JoyRest | покажет настройка (PR 3) один раз | вход в студию |

## Первичная настройка сервера

### 1. Ключ для входа (Termius)

1. Termius → **Keychain** → **+** → **Generate Key**.
2. Тип **ED25519**, имя `joyrest` → **Save**.
3. Откройте ключ → **Export** / **Copy public key**. Строка начинается с `ssh-ed25519`.
   Её спросит установка.

### 2. Токен GitHub для скачивания образов

1. github.com в браузере → аватар → **Settings** → **Developer settings** →
   **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**.
2. Note: `joyrest-server-pull`. Expiration: **1 год** (запишите дату).
3. Отметьте **только** `read:packages` → **Generate token** → скопируйте токен.

### 3. Проверка связи

Termius → новый хост: адрес `217.114.13.92`, пользователь `root`, пароль из Beget.
Вставьте блок из сообщения Claude (файл `deploy/setup/check.sh`) и запустите:

```
bash check.sh
```

Скрипт ничего не меняет. Пришлите скриншот итоговой таблицы.

### 4. Установка

Вставьте блок с `install.sh` из сообщения Claude, затем:

```
bash install.sh
```

Скрипт спросит:
- почту администратора (Enter — `student.maik@gmail.com`);
- имя вашего пользователя (Enter — `joy`);
- публичный ключ из шага 1;
- токен из шага 2 (при вставке символы не видны, это нормально).

В конце скрипт **один раз** покажет два секрета: `DEPLOY_SSH_KEY` и `DEPLOY_KNOWN_HOSTS`.
Каждый — одна длинная строка: двойное касание выделяет её целиком.

### 5. Секреты в GitHub

github.com → репозиторий `joyrest-games` → **Settings** → **Secrets and variables** →
**Actions** → **New repository secret**. Создайте:
- `DEPLOY_SSH_KEY` — первая строка из шага 4;
- `DEPLOY_KNOWN_HOSTS` — вторая строка из шага 4.

### 6. Проверка входа по ключу

В Termius создайте **новый** хост: адрес `217.114.13.92`, пользователь `joy`, ключ `joyrest`
(без пароля). Подключитесь и выполните:

```
joyrest status
```

### 7. Перезагрузка и проверка, что всё поднялось само

Установка обновила систему и, скорее всего, ядро. Новое ядро начинает работать только после
перезагрузки, а заодно проверим главное: после перезапуска сервера сайт встаёт без вашего участия.

1. Под `joy` проверьте, нужна ли перезагрузка:

```
[ -f /var/run/reboot-required ] && echo "Нужна перезагрузка" || echo "Перезагрузка не нужна"
```

2. Перезагрузите (Termius отключится — это нормально):

```
sudo reboot
```

3. Подождите 2 минуты, подключитесь снова под `joy` и выполните:

```
uname -r && joyrest status
```

Все три сервиса должны быть `Up`, у `app-prod` и `postgres` — `(healthy)`, в строке
«Здоровье» — `"ok":true`. Если `app-prod` ещё `starting`, подождите минуту и повторите.

4. В браузере телефона откройте https://games.joy-rest.ru/health — `"ok":true`,
и https://joy-rest.ru — заглушка «Радость без хлопот».

Если через 5 минут сайт не поднялся: `sudo joyrest up`, затем `joyrest logs 100` —
скриншот пришлите Claude.

### 8. Запрет входа root и паролей

Только после того, как вход `joy` по ключу работает и выкладка из GitHub проверена.
Войдите как `joy` и вставьте блок из файла `deploy/setup/lock-ssh.sh`, затем:

```
sudo bash lock-ssh.sh
```

Не закрывая окно, проверьте вход в новом подключении.

## Каждый день

Все команды — под пользователем `joy`.

### Всё ли в порядке

```
joyrest status
```

Покажет версию, состояние контейнеров (`healthy` — хорошо), диск, память и сколько памяти
занимает каждый контейнер. Из браузера: https://games.joy-rest.ru/health — `"ok":true`.

### Логи

```
joyrest logs app-prod 100
```

Вместо `app-prod` можно указать `caddy` (HTTPS и сертификаты) или `postgres` (база).
Без названия — логи всех сервисов. Логи хранятся до 30 МБ на контейнер, старые удаляются сами.

### Перезапуск

```
sudo joyrest restart app-prod
```

Без названия перезапускается всё. Гости и экран зала переподключатся сами.

### Обновления системы и перезагрузка

Обновления безопасности ставятся сами каждую ночь, но сервер сам **не** перезагружается
(чтобы не оборвать праздник). Раз в неделю проверьте:

```
[ -f /var/run/reboot-required ] && echo "Нужна перезагрузка" || echo "Перезагрузка не нужна"
```

Если нужна — в день без мероприятий: `sudo reboot`, через 2 минуты `joyrest status`
(как в шаге 7 настройки). Сайт будет недоступен около минуты.

### Поставить конкретную версию

```
sudo joyrest activate main
```

Вместо `main` можно указать `sha-<коммит>`: так возвращают прошлую версию.
С PR 2 выкладка и откат будут автоматическими.

## Если что-то сломалось

- **Сайт не открывается.** `joyrest status`. Если контейнер не `Up` —
  `sudo joyrest restart`, затем `joyrest logs <сервис> 200`. Скриншот пришлите Claude.
- **Ошибка сертификата.** `joyrest logs caddy 200`. Проверьте, что в DNS Beget домены
  указывают на `217.114.13.92`.
- **Не пускает по ключу.** Панель Beget → VPS → **Консоль (VNC)** → вход `root` с паролем
  из панели. Запрет входа root касается только SSH, консоль Beget работает всегда.
- **Диск заполнен.** `joyrest status` (строка «Диск»), затем `sudo docker image prune -a`:
  команда удаляет образы, которые сейчас не используются.

Откат выкладки, восстановление из бэкапа и мониторинг появятся в этом файле
вместе с PR 2 и PR 6.
