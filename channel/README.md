# Очередь Telegram-канала JoyRest

`queue.json` — посты, которые бот JoyRest публикует в t.me/JoyRest в назначенное время (`server/src/channel.ts`).
Ролики — `video/*.mp4` (вертикальные 1080×1920, до 10 с). Очередь попадает на сервер с релизом основной версии.

Поля поста: `id` (латиница, цифры, дефис; не меняется), `n` (номер для команды /skip_N), `at` (время с поясом +03:00),
`text` (подпись, до 1024 знаков с роликом), `video` (имя файла в `video/`), `pin` (закрепить после публикации).
Вышедший пост сервер больше не трогает; ещё не вышедший — обновляется при следующем релизе.

Команды владельца боту: /channel — что впереди, /pause — остановить, /resume — продолжить, /skip_N — не публиковать пост N.
