# Шаблон существа

Единая карточка для всех существ: врагов, боссов, дружественных персонажей, демонов, пожирателей, душ, стражей. Даже дружественное существо получает рейтинг и характеристики — по сюжету оно может стать врагом.

Данные для игры: `данные/creature.example.json`.

## Поля

| Поле | Заполнить | Подсказка |
| --- | --- | --- |
| Имя | | |
| Код | | `CR-001` |
| Тип | | бог / раса / чудовище / демон / пожиратель / душа / страж / смертный |
| Мир обитания | | где живёт и где сильнее всего |
| Рейтинг | | F, E, D, C, B, A, S, SS, SSS |
| Рост вместе с группой | | по рейтингу: F 70% … SSS 120% (120% только в финале истории) |
| Мощь | | 0–100 |
| Мудрость | | 0–100 |
| Хитрость | | 0–100 |
| Влияние | | 0–100 |
| Стойкость | | 0–100 |
| Удача | | 0–100 |
| Здоровье | | 0–100 (боссы — до 300) |
| Способности | | 1–3 особых действия |
| Слабость | | из мифа или лора |
| Поведение | | агрессивный / хитрый / охраняет / торгуется / дружелюбный |
| Отношение к игрокам на старте | | −100…+100; ниже −50 — становится врагом |
| **Скрытая сила** | | неизвестна ни ведущему, ни игрокам до раскрытия |
| **Условие раскрытия** | | здоровье < 50%, крит. неудача рядом, нарушенная клятва, ночь, мир… |
| Награда | | очки, артефакт, проход, союзник |
| Лор | | 1–3 абзаца: кто это, откуда, чего хочет, связь с мифом |

## Пример: Харон

| Поле | Значение |
| --- | --- |
| Тип | страж |
| Мир | Царство Аида, река Стикс |
| Рейтинг | D (видимый) |
| Характеристики | Мощь 35, Мудрость 55, Хитрость 45, Влияние 40, Стойкость 50, Удача 30 |
| Здоровье | 45 |
| Способности | Перевоз: только он может переправить через Стикс |
| Слабость | не повезёт без платы — монеты за переправу |
| Поведение | торгуется |
| Отношение на старте | 0 |
| Скрытая сила | Гнев Стикса: топит лодку, все в ней получают −20 здоровья; рейтинг становится A |
| Условие | обман при оплате или отношение ниже −50 |
| Награда | проход в Аид; при дружбе — тайный путь к Лете |
| Лор | Древний перевозчик душ. Видел всех, кто когда-либо умирал, и помнит каждую неоплаченную душу. |
