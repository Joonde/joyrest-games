# Миграции базы

Файлы `NNNN_название.sql` (латиница, цифры, `_`) выполняются по порядку при выкладке,
каждый в своей транзакции (`server/src/migrate.ts`). Выполненные записаны в `schema_migrations`.

Миграции обратно совместимы (expand/contract): они выполняются до переключения версии, а
откат возвращает прошлый код, но не схему. Можно: новые таблицы, колонки с `default` или
без `not null`, индексы. Нельзя в обычной миграции: `drop`, `rename`, смена типа,
`set not null`, `not null` без `default`, `truncate`, `delete`.

Удаление — отдельная contract-миграция, не раньше чем через релиз после того, как код
перестал пользоваться удаляемым. Первая строка файла:

```sql
-- contract: games.title не используется с релиза <коммит>
```

Переименование: новая колонка → код пишет в обе и читает новую → contract-миграция удаляет
старую. Правила проверяет тест `server/src/migrationRules.test.ts`.
