# Танцевальный батл — галерея конструктора и игры

Локальная галерея из 11 состояний настоящих компонентов JoyRest: общие настройки, четыре типа карточек и полный игровой процесс.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Снимки в `assets/` получены в Chromium после сквозной проверки конструктора. Это не production и не отдельная игровая логика.
