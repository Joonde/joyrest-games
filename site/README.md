# JoyRest — сайт агентства «Радость без хлопот» (joy-rest.ru)

Сайт собирается в тот же образ, что и платформа, и выкладывается вместе с ней
(CLAUDE.md, «Сайт агентства»): `main` → joy-rest.ru, ветки `claude/*` → test.joy-rest.ru (по паролю).
Пока сайт выключен: на joy-rest.ru заглушка «скоро», включает владелец — `sudo joyrest site on`.

Дизайн — «Вечерняя сцена» (вариант B, 12 октября 2026). Прежний сайт — резервная копия
`site-archive/v1-2026-10-12/` (на сервер не выкладывается).

Структура:
- index.html — главная страница
- css/style.css — стили (вечерняя и дневная тема, телефон / планшет / компьютер), css/fonts.css — шрифты
- js/theme.js — тема до отрисовки страницы (выбор посетителя в localStorage)
- js/pricing.js — цены пакетов и расчёт калькулятора (чистая функция calcPrice, её проверяет server/src/sitePricing.test.ts)
- js/script.js — логика: меню, тема, калькулятор, обзор игр, правила, формы (POST /api/lead)
- img/ — картинки
- fonts/ — не храним: сборка берёт файлы платформы из public/fonts/
- материалы (промо-ролик, описание сайта, статья для Дзена, сетка логотипов, описание игр) —
  в docs/site-extras/, на сайт не выкладываются

Сборка: `npm run build:site` → build/site (отпечаток содержимого в именах css/js/img).
Внешних ресурсов нет: вместо виджета Telegram — своя карточка канала с QR-кодом (его встраивает сборка).

Заявки: формы шлют POST /api/lead на сервер, сервер пересылает в Telegram. Токена бота
в коде сайта нет и быть не должно — он хранится только на сервере
(/srv/joyrest/secrets.env, команда `sudo joyrest lead-bot`, RUNBOOK.md).
Если токен где-то засветился — перевыпустите его у @BotFather (/mybots → бот → API Token → Revoke).
