# ТЗ: сворачивание блока «Популярные» в библиотеке

Дата: 22.11.2026.

## Цель

Блок «Популярные» не должен занимать всю страницу библиотеки. По умолчанию он отображается свёрнутым, как другие разделы.

## Поведение

- При открытии библиотеки видны только заголовок «Популярные», пояснение, количество игр и стрелка.
- По касанию на заголовок блок разворачивается и показывает карточки игр.
- Повторное касание сворачивает блок.
- `aria-expanded` и `aria-controls` соответствуют состоянию; управление доступно с клавиатуры.
- При повторном открытии страницы блок снова свёрнут — специального запоминания открытого состояния не требуется.

## Что не меняется

- Состав игр, `popularGames`, порядок слотов и их дублирование в обычных разделах.
- Карточки игр, запуск, редактирование, копирование, предложения, папки и права доступа.
- Остальные блоки библиотеки и игровая логика.
- Механика «Танцуй иначе» и остальная платформа.

## Реализация

Только `src/screens/studio/GameList.tsx`:

- добавить локальный `popularOpen = false`;
- заменить статичный заголовок на `category-row` по образцу соседних разделов;
- показывать список только при `popularOpen === true`.

CSS не требуется: используются существующие стили `category`, `category-row`, `category__games`.

## Проверки

1. TypeScript и сборка.
2. Полный `npm test`.
3. На test: блок свёрнут, список отсутствует в DOM, счётчик совпадает с числом игр.
4. По касанию список появляется, все ожидаемые карточки видны; повторное касание скрывает их.
5. `aria-expanded` переключается `false → true → false`.
6. Нет ошибок консоли, горизонтальной прокрутки на телефоне и изменения состава игр.
7. Production `/health` подтверждает новую версию, прежняя функциональность библиотеки сохранена.

## Откат

Изменение ограничено одним файлом. Откат коммита возвращает прежний всегда раскрытый блок без миграций и изменения данных.
