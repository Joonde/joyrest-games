# «Бункер» — правила, по которым сделана механика

Источники: правила настольной игры «Бункер» (редакции 3.x), сводки правил на nastolnie-igri.ru,
hobbygames.ru, korpigra.ru, kp.ru, gamerules.ru, fakemafia.org. Тексты карт написаны для JoyRest заново.

## Состав
- 4–16 игроков. Мест в бункере — половина игроков, округление вниз:
  4–5 → 2, 6–7 → 3, 8–9 → 4, 10–11 → 5, 12–13 → 6, 14–15 → 7, 16 → 8.
- Катастрофа (одна на игру): что случилось, что снаружи, сколько лет сидеть в бункере.
- 5 карт бункера (что в нём есть) — открываются по одной в начале раунда.
- Персонаж каждого — 6 карт: Профессия (со стажем), Биология (пол, возраст), Здоровье, Хобби,
  Багаж, Факт. Плюс одна карта «Особое условие» (если включены).

## Раунд (по умолчанию 5)
1. **Исследование бункера** — открывается карта бункера этого раунда.
2. **Круг открытия** — игроки по очереди (каждый раунд начинает следующий) открывают по одной
   своей карте. В первом раунде все открывают **Профессию**. Речь — 60 с в первом раунде, 30 с дальше.
3. **Обсуждение** — общий таймер (60 с).
4. **Голосование** — тайно, на телефонах, за себя нельзя. Больше всех голосов — изгнан.
   - Ничья: каждому из ничьей — оправдательная речь (30 с), переголосование только между ними;
     снова ничья — жребий.
   - Изгнанный открывает все карты. Голосуют ли изгнанные — настройка: нет / один общий голос
     всех изгнанных (по большинству).
5. **Сколько изгонять**: лишние (игроки − места) распределяются по раундам, остаток — в последние
   раунды: 4 игрока — 0, 0, 0, 1, 1; 6 — 0, 0, 1, 1, 1; 10 — по 1; 16 — 1, 1, 2, 2, 2. Если в раунде
   изгоняют двоих — два голосования подряд. Ведущий может один раз пропустить голосование —
   изгнание переносится на следующие раунды.

## Особые условия (23 карты, каждая — один раз)
Обмен багажом / здоровьем / хобби / фактом / профессией · Переобучение (новая профессия) ·
Медкомиссия (новое здоровье другому) · Чудесное исцеление (себе) · Таблетка от всего (другому) ·
Заразный (здоровье другого = ваше) · Карманник (забрать багаж) · Шпион (подсмотреть карту, видите
только вы) · Допрос (игрок открывает названную карту) · Детектор лжи (все открывают факты) ·
Неприкосновенность*, Решающий голос*, Отмена голосования* (*только во время голосования; отмена
нельзя в последнем раунде) · Лишняя койка (+1 место) · Обвал (−1 место) · Второй шанс (последний
изгнанный возвращается) · Эпидемия (перемешать здоровье) · Переполох на складе (перемешать багаж) ·
Перепланировка (заменить последнюю открытую карту бункера).

## Финал
- Открываются все карты спасшихся и все карты бункера.
- **«Возрождение»** (настройка, лучше от 8 игроков): среди спасшихся нужны мужчина и женщина
  18–55 лет без бесплодия — иначе бункер не выживет.
- **«История выживания»**: 0–3 карты угроз; спасшиеся обсуждают, чем справятся, ведущий решает.
- Бункер выжил → каждому спасшемуся +100. Каждый пережитый раунд → +10 всем в игре. Потом награждение.

## Тайна карт
Каждый телефон присылает свой ключ (AES-GCM); пульт шифрует персонажа этим ключом, всё тайное игры —
ключом ведущего (на устройстве пульта). Открытые карты лежат в состоянии игры открыто. Все шифры
одной длины.
