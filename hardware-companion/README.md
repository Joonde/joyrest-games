# JoyRest Кнопки — локальный канал (аппаратный spike)

Временная локальная программа для проверки архитектуры физических кнопок. Сейчас в ней только виртуальные Bluetooth- и USB-устройства; реальных драйверов оборудования пока нет.

## Запуск

```bash
npm start
```

Программа слушает только `127.0.0.1:43127` и печатает одноразовый шестизначный код сопряжения. После успешного сопряжения код становится недействительным; токен живёт в памяти программы и удаляется при её остановке.

## Проверка

```bash
npm test
```

Проверяются:

- health и обязательная авторизация устройств;
- одноразовый код сопряжения;
- CORS и Private Network Access preflight для `https://test.games.joy-rest.ru`;
- запрет постороннего origin;
- виртуальное нажатие и его доставка через SSE;
- одновременные нажатия двух устройств без потерь и с разными `eventId`;
- закрытие SSE без зависания.

Дополнительно проверен полный путь события через браузерный клиент `src/data/localHardware.ts`: два одновременных нажатия доставляются из локальной программы в SSE-клиент. Пульт маршрутизирует событие в серверный `hardware-buzz`.

## API

- `GET /health` — состояние без технических секретов.
- `POST /pair` — `{ "code": "……" }`, одноразовое сопряжение.
- `GET /api/devices` — виртуальные устройства, нужен `Authorization: Bearer …`.
- `GET /api/events` — SSE с `ready`, `ping` и `press`, нужен токен.
- `POST /api/virtual/press` — виртуальное нажатие, нужны токен и `X-JoyRest-Hardware: 1`.

Пример нажатия:

```json
{
  "source": "bluetooth",
  "hardwareId": "bt-demo-1"
}
```

Событие содержит `eventId` и `localPressedAt`. Они не определяют победителя: окончательное время и порядок по-прежнему ставит сервер JoyRest.

## Подтверждённый сценарий 18 ноября 2026

Со страницы `https://test.games.joy-rest.ru` в Chromium встроенного браузера Kimi Work:

1. `GET /health` — 200.
2. Сопряжение — 200.
3. Список устройств — 200.
4. SSE — 200, получено `ready`.
5. Виртуальное Bluetooth-нажатие — 200.
6. В SSE получено то же событие с совпадающим `eventId`.

Это подтверждает только локальный канал и виртуальный адаптер. Совместимость с физическими Bluetooth/USB-моделями ещё не проверена.
